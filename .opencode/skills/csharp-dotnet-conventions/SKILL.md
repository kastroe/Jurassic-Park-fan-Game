C# conventions: Follow Microsoft .NET naming guidelines (PascalCase for methods/properties, camelCase for params/fields). Prefer async/await, LINQ over loops, records over classes for DTOs. Use dependency injection via constructor. Activate when writing or reviewing C#/.NET code.
