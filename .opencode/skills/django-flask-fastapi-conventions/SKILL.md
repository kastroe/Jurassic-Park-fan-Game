Python web conventions: FastAPI for new projects (auto-docs, Pydantic validation). Django for full-featured apps (admin, ORM, auth). Flask for minimal APIs. Use Pydantic/Zodat for validation, async where the framework supports it. Activate when writing or reviewing Python web code.
