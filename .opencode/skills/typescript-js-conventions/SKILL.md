TS/JS conventions: Prefer const over let, never use var. Use arrow functions, optional chaining, nullish coalescing. TypeScript: strict mode, explicit return types on public APIs, prefer interfaces over types for object shapes, discriminated unions over enums. ESM imports, no default exports for functions. Activate when writing or reviewing TS/JS code.
