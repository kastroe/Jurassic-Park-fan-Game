Rust conventions: Follow rustfmt/clippy. Use Result/Option, avoid unwrap/expect (prefer ?). Prefer iterators over loops. Use enums over string matching. Structure: mod.rs for modules, lib.rs for library crate. Activate when writing or reviewing Rust code.
