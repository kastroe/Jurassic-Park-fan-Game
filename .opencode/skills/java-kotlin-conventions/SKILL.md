Java/Kotlin conventions: Follow Google Java Style / Kotlin coding conventions. Use Optional over null, streams over loops, records (Java 16+) over POJOs. Kotlin: prefer data classes, use scope functions (let/apply/run) judiciously, prefer immutability (val over var). Activate when writing or reviewing JVM code.
