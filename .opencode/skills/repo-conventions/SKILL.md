Repo conventions: Before writing any new code, read: (1) existing files in the same directory, (2) any config files (tsconfig, eslint, rustfmt.toml), (3) other files of the same type to match style. This is the highest-leverage single skill — matching existing patterns prevents the most common agent mistakes. Activate on every new task in an unfamiliar repo.
