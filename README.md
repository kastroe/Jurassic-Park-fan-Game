# Jurassic Park 1993 Fan Game

An unofficial fan-made Unreal Engine project inspired by **Jurassic Park (1993)**.

The goal is to recreate a playable version of Isla Nublar based primarily on the original film, with a focus on the park layout, Tour Road, major landmarks, and the overall feel of the 1993 movie.

## Current Status

The project is in active development.

Current work includes:

- Reconstructed Isla Nublar terrain
- Film-inspired park landmark layout
- Visitor Center placement
- Jurassic Park Main Gate placement
- T-Rex paddock location
- Tour Road route
- Jurassic Park-style vehicle guide track
- Local roadbed grading
- Automated Unreal build and verification tools

The current Tour Road route is approximately **5.9 km long** and remains entirely on dry land.

## Engine

Built with:

**Unreal Engine 5.8 / 5.8.1**

Development is currently focused on:

- environment construction
- smoother Tour Road geometry
- park infrastructure
- paddocks and fences
- vegetation
- vehicle systems
- gameplay systems

## Isla Nublar

The terrain is based on recovered terrain data from the older **Jurassic Dream** CryEngine fan project.

That terrain is being used as the physical island foundation, while the actual park layout is being rebuilt around the **Jurassic Park 1993 film** rather than copying the Jurassic Dream layout directly.

## Jurassic Park Tour

The current planned tour route includes:

**Visitor Center → Main Gate → Brachiosaurus → Gallimimus → Triceratops → T-Rex Paddock → Dilophosaurus → Visitor Center**

The road uses a centered guide track inspired by the automated Ford Explorer system shown in the film.

## Development

A large amount of the project is being built through automation using:

- Unreal Engine C++
- Unreal Python
- OpenCode
- scripted verification
- Git / Git LFS

The aim is to make large-scale environment work repeatable while avoiding unnecessary manual placement and destructive editor operations.

## Version Control

Major project milestones are backed up through Git and GitHub.

Important changes are checkpointed before and after major work so maps and Unreal assets can be safely restored if something goes wrong.
