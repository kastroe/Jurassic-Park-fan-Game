height domain. Pixels outside the island mask are set to raw height 48, the
lowest masked island value. The output remains grayscale 16-bit PNG.

Heightmap direction
-------------------
The source README identifies north as local +Y in the reference OBJ. Keep the
prepared PNG row order unchanged for the first test import. Use Flip Y Axis
unchecked initially; if the visual overlay proves north/south reversed, repeat
the test import with Flip Y Axis enabled rather than changing production data.
